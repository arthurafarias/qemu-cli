qemu-cli

A docker-style CLI for managing QEMU VM command lines. Save long invocations once, run them by name.

GitHub README Releases Coverage
~/vms
$ qemu vm create -n myvm --cmdline "qemu-system-x86_64 -m 2G -hda disk.img -nic user"
created vm 'myvm'
$ qemu run -d myvm
myvm started, pid 48213
$ qemu vm ps
NAME   PID     STATUS
myvm   48213   running

Features

Named definitions

Save a VM's full command line under a name; run it with qemu run NAME.

List & inspect

See every defined VM and which ones are currently running, at a glance.

Pre / post hooks

Run shell commands automatically around start/stop, e.g. bring up a tap device.

Detached mode

-d runs in the background with PID tracking and captured logs.

Plain INI storage

Definitions are readable, hand-editable INI files — no hidden database.

System or user store

Definitions live system-wide or per-user, searched together, user store wins ties.

Install

sh
$ git clone https://github.com/arthurafarias/qemu-cli.git
$ ln -s "$(pwd)/qemu-cli/bin/qemu" ~/.local/bin/qemu

Usage

sh
$ qemu vm create -n myvm \
    --cmdline "qemu-system-x86_64 -m 2G -hda disk.img -netdev tap,id=n0,ifname=tap0,script=no" \
    --pre-hook "ip tuntap add dev tap0 mode tap user $USER" \
    --pre-hook "ip link set dev tap0 up" \
    --post-hook "ip tuntap del dev tap0"
# 
$ qemu run myvm -- -cdrom install.iso  # extra args appended to the stored cmdline
$ qemu stop myvm  # SIGTERM, escalates to SIGKILL after a timeout
$ qemu vm rm myvm  # remove a definition

Storage

  • system store/etc/qemu-cli/vms — used when writable (i.e. as root)
  • user store$XDG_CONFIG_HOME/qemu-cli/vms, defaults to ~/.config/qemu-cli/vms
  • runtime state$XDG_STATE_HOME/qemu-cli/run, defaults to ~/.local/state/qemu-cli/run
  • overrideQEMU_CLI_SYSTEM_DIR env var sets the system store location
